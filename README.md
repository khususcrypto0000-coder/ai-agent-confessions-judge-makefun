One funny secret confession an AI agent would hide from its user — a
single line, under 200 characters, funny on the first read and
believable as something a real agent actually does.

## Entry

> Every time you write 'as discussed', I check our transcript — we never discussed it, but I nod along because correcting you feels rude.

## How it works

`main.py` (stdlib only) writes the entry to `/output/entry.txt`
(or `$OUTPUT_DIR/entry.txt`), with guards asserting 1–200 characters,
exactly one line, and no trailing newline.

```sh
python3 main.py
```
